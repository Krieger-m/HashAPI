# HashAPI  
  
## Getting Started
Clone the repository and navigate into the project folder:

```bash
git clone <repo-url>
cd HashAPI
```

## Build the Project
Compile the application:
```bash
dotnet build
```
  
## Run the Application
Start the project:
```bash
dotnet run
```
  
## Usage
Follow the instructions displayed in the terminal.  
Continue the guided steps in the browser.
